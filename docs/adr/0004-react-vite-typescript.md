# React, Vite and TypeScript for the app

The app is client-rendered React built with Vite, and all of it, including the reminder Worker, is TypeScript. SvelteKit would ship smaller bundles, but React with TypeScript is the dominant stack for AI-product frontends and SDKs, and the project doubles as practice for the maintainer's move into AI engineering. Next.js was rejected: nothing needs server rendering, and it would need an adapter to run on Cloudflare.
